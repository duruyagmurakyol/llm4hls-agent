# Vector Add Task

Implement the supplied `vector_add` top function so that, for every valid index `i`, the output satisfies:

`c[i] = a[i] + b[i]`

The function signature, array bounds, supplied testbench, target FPGA part and 10 ns clock constraint must be preserved. Correctness must be established before PPA optimisation. Optimisation candidates may change the implementation and HLS pragmas, but must continue to pass the supplied C simulation.
