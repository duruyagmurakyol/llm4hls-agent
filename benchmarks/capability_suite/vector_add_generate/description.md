# Vector-add generation task

Implement `vector_add_generate` for arrays of length `N`.

For every valid index `i`:

```text
out[i] = a[i] + b[i]
```

Preserve the function signature declared in `vector_add_generate.h`. The source
must pass the public testbench and synthesize with AMD Vitis HLS. Do not modify
the header or testbench.
